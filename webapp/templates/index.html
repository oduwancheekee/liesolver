LieSolver

LieSolver approximates PDE solutions as a linear combination of Lie-symmetry transformed start functions. Each "brick" is a known analytical solution (e.g. sin(x)·exp(-t)) reshaped by one or more Lie-group transformations. The model greedily adds bricks, fitting amplitudes via linear regression and refining nonlinear parameters.

Configuration hints
  • pde — PDE module name (e.g. heat_1d, wave_1d).
  • data.constraints — initial/boundary conditions: each entry has expr (math expression), loc (which variable is fixed and its value), and num_samples.
  • bricks — list of brick family strings. Each is a sequence of transformations (e.g. T4 T1(0,3.14) sin(x) exp(-t)). Parameters in parentheses set initial search ranges.
  • fit.max_bricks — maximum number of bricks to add.
  • fit.mse_tol — stop when training MSE drops below this.
  • fit.pool_size — candidates sampled per brick addition (larger = slower but better).
  • fit.global_every — refine all parameters every N bricks.
